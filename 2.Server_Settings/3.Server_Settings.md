# ⚙️ Server Documentatie & Configuratie

Dit document beschrijft de geavanceerde serverinstellingen, waaronder het activeren van specifieke vanilla mechanics en het beveiligen van commando-suggesties.

## 💣 1. Vanilla Bugs & Exploits (Paper)

Dit onderdeel beschrijft hoe bekende "vanilla bugs" zoals TNT duping en het breken van bedrock zijn geconfigureerd. Omdat de server draait op Paper, zijn deze exploits standaard streng geblokkeerd en vereisen ze specifieke configuratie.

**Bestandslocatie:** `/config/paper-global.yml`

Om TNT dupers (inclusief carpets en rails) en machines die bedrock breken te laten werken, zijn de volgende waarden onder het kopje `unsupported-settings:` op `true` gezet:

```yaml
unsupported-settings:
  allow-headless-pistons: true
  allow-permanent-block-break-exploits: true
  allow-piston-duplication: true
```

- **`allow-headless-pistons`**: Vereist voor de meeste piston-gebaseerde bedrock-breaking machines.
- **`allow-permanent-block-break-exploits`**: Maakt het mogelijk om onbreekbare blokken (zoals Bedrock of End Portal frames) te breken.
- **`allow-piston-duplication`**: Schakelt de exploit in waarmee TNT, tapijten en rails gedupliceerd kunnen worden via slimeblocks en pistons.

> ⚠️ **Let op:** Na het wijzigen van deze instellingen is een **volledige server herstart** vereist.

## 📝 2. Tab-Complete Beveiliging

Dit document beschrijft hoe tab-complete (commando-suggesties in de chat) veilig is ingesteld. Dit voorkomt dat spelers commando's kunnen zien in de lijst waar ze geen permissie voor hebben (zoals `/drivebackup` voor de `default` rank).

**Bestandslocatie:** `/spigot.yml`

Onder het kopje `commands:` is de waarde voor tab-complete aangepast naar `-1`:

```yaml
commands:
  tab-complete: -1
```

- **`tab-complete: -1`**: Dwingt de server om éérst de LuckPerms permissies te verifiëren voordat de commando-suggesties naar de speler worden gestuurd bij het inloggen. Als een speler de permissie voor een commando mist of als de permissie op `false` staat, verschijnt het woord niet meer in de chat tijdens het typen.

> ⚠️ **Let op:** Na het wijzigen van deze instelling in `spigot.yml` is een **volledige server herstart** (restart via de console) vereist om de wijziging actief te maken. Alleen de server opnieuw betreden (rejoinen) is niet voldoende.
