# ⚙️ 3. Server Documentatie & Configuratie

Dit document beschrijft de geavanceerde serverinstellingen, waaronder het activeren van specifieke vanilla mechanics, het instellen van snelkoppelingen en het configureren van het server-menu.

## 💣 3.1 Vanilla Bugs & Exploits (Paper)

Dit onderdeel beschrijft hoe bekende "vanilla bugs" zoals TNT duping en het breken van bedrock zijn geconfigureerd. Omdat de server draait op Paper, zijn deze exploits standaard streng geblokkeerd en vereisen ze specifieke configuratie.

**Bestandslocatie:** `/config/paper-global.yml`

Om TNT dupers (inclusief carpets en rails) en machines die bedrock breken te laten werken, zijn de volgende waarden onder het kopje `unsupported-settings:` op `true` gezet:

```yaml
unsupported-settings:
  allow-headless-pistons: true
  allow-permanent-block-break-exploits: true
  allow-piston-duplication: true
```

- **`allow-headless-pistons`**: Vereist voor de meeste piston-gebaseerde bedrock-breaking machines.
- **`allow-permanent-block-break-exploits`**: Maakt het mogelijk om onbreekbare blokken (zoals Bedrock of End Portal frames) te breken.
- **`allow-piston-duplication`**: Schakelt de exploit in waarmee TNT, tapijten en rails gedupliceerd kunnen worden via slimeblocks en pistons.

> ⚠️ **Let op:** Na het wijzigen van deze instellingen is een **volledige server herstart** vereist.

## 🖼️ 3.2 Server Icon (Branding)

Dit onderdeel beschrijft de vereisten voor het instellen van een aangepast serverlogo in de Minecraft multiplayer lijst.

**Bestandslocatie:** De hoofdmap van de server (dezelfde map als `server.properties`).

Om het logo succesvol te laden, moet het bestand aan drie eisen voldoen:
1. **Bestandsnaam:** Exact `server-icon.png` (alles in kleine letters, streepje in het midden).
2. **Afmetingen:** Exact **64x64 pixels**.
3. **Bestandstype:** Een `.png` bestand.

## 🔀 3.3 Commando Aliassen (Snelkoppelingen)

Dit onderdeel beschrijft hoe je standaard commando's kunt overschrijven of doorverwijzen via de basisbestanden van de server. We gebruiken dit voor een aangepast report-systeem, het koppelen van info commando's en het oplossen van conflicten.

**Bestandslocatie:** `/commands.yml` (in de hoofdmap van de server)

Om de aliassen in te stellen, zoek je naar het kopje `aliases:` en voeg je de volgende regels toe. Let hierbij extreem goed op de spaties (inspringing):

```yaml
aliases:
  v:
  - "sv $1-"
  - "essentials:vanish $1-"
  vanish:
  - "sv $1-"
  - "essentials:vanish $1-"
  report:
  - "helpop $1-"
  info:
  - "essentials:info $1-"
  help:
  - "essentials:info $1-"
  ban:
  - "libertybans:ban $1-"
  mute:
  - "libertybans:mute $1-"
  kick:
  - "libertybans:kick $1-"
  unban:
  - "libertybans:unban $1-"
```

### 👻 Uitleg Vanish Aliassen (`v` en `vanish`)
SuperVanish en EssentialsX hebben soms ruzie over wie je mag verbergen op de TAB-lijst. Door deze alias voert de server razendsnel twee commando's tegelijk uit als je `/v` typt:
1. Het activeert SuperVanish (voor onzichtbaarheid in de wereld).
2. Het activeert direct `essentials:vanish` (zodat je succesvol van de TAB-lijst verdwijnt).
*De code `$1-` zorgt ervoor dat als je extra tekst typt (bijv. `/v [spelernaam]`), dit netjes wordt doorgegeven.*

### 🚨 Uitleg Report & Help Aliassen
- **`report`**: Zorgt ervoor dat normale spelers `/report <bericht>` kunnen gebruiken. Dit wordt doorgestuurd naar het EssentialsX `/helpop` commando (alleen zichtbaar voor staff).
- **`help` & `info`**: Verwijst spelers die `/help` of `/info` typen direct door naar het aangepaste `essentials:info` commando, zodat het regels-menu altijd geforceerd wordt getoond.

### 🔨 Uitleg LibertyBans Aliassen
Er is een conflict tussen EssentialsX en LibertyBans over de moderatie-commando's (`ban`, `mute`, enz.). Deze aliassen dwingen de server om altijd het systeem van LibertyBans te gebruiken in plaats van dat van EssentialsX.

> ⚠️ **Let op:** Na het opslaan van dit bestand moet de server opnieuw worden opgestart.

## ℹ️ 3.4 Info Commando Instellen

Dit document beschrijft hoe je de commando's `/info` en `/help` instelt om spelers een overzicht te geven van de regels en contactmogelijkheden.

Dit maakt gebruik van de ingebouwde tekstbestanden van EssentialsX. Omdat de ingestelde tekst langer is dan 9 regels, zal EssentialsX dit menu in-game automatisch opknippen in meerdere pagina's (te lezen via `/info 2`).

### 📝 Stap 1: Het info.txt bestand aanmaken

1. Ga in het Pterodactyl paneel naar **Files** en open de map `/plugins/Essentials/`.
2. Klik rechtsboven op **New File** (of bewerk het bestaande bestand).
3. Kopieer en plak de onderstaande code in het lege bestand. De `&` codes zorgen voor de juiste kleuren in-game.

```text
&8&m-----------------------------------------------------
&6&l🌟 SERVER INFORMATIE & REGELS 🌟
&8&m-----------------------------------------------------
&e1. &fGeen hacks, cheats of oneerlijke mods toegestaan.
&e2. &fNiet griefen of stelen (alles wordt gelogd!).
&e3. &fHeb respect voor elkaar. Geen racisme, spam of schelden.
&e4. &fLuister altijd naar de aanwijzingen van het Staff-team.

&b&l📞 Hulp Nodig?
&7Zie je iemand de regels overtreden of heb je hulp nodig?
&7Gebruik in-game het commando: &c/report <jouw bericht>

&9&l💬 Join onze Discord!
&fBlijf op de hoogte en chat met ons via:
&b[https://discord.gg/hQmxpFyGmK](https://discord.gg/hQmxpFyGmK)
&8&m-----------------------------------------------------
```

4. Pas de tekst eventueel verder naar wens aan.
5. Klik op **Save Content** en noem het bestand exact: `info.txt`.
6. Voer in de console (of in-game) het commando `ess reload` uit.

### 🔀 Stap 2: Zorgen dat het werkt voor spelers

Om te garanderen dat spelers deze tekst zien, zijn de commando's in `commands.yml` (zie sectie 3.3) via aliassen doorgestuurd naar `essentials:info`. 

**Belangrijke permissie-check:**
Zorg ervoor dat je in de **LuckPerms Web Editor** voor de `default` groep de volgende twee permissies op `true` hebt gezet, anders werkt het menu niet voor normale spelers:
- `essentials.info`
- `essentials.help`

## 💎 3.5 Beveiliging: Anti-Xray & Command Blocks

Dit onderdeel beschrijft de belangrijkste instellingen om de server te beschermen tegen cheaters (X-rayers) en ongewenste server-commando's via blokken.

### 1. Anti-Xray Activeren (Paper)
De server maakt gebruik van de ingebouwde Anti-Xray van PaperMC. In plaats van ertsen te verbergen (wat server-lag kan veroorzaken), vult deze methode de muren met 'nep' ertsen voor spelers die hacks gebruiken, waardoor hun X-ray nutteloos wordt.

**Bestandslocatie:** `/config/paper-world-defaults.yml` *(bij oudere versies: `/paper.yml`)*

Zoek in het bestand naar het kopje `anti-xray:` en pas de volgende twee waarden aan:
```yaml
anti-xray:
  enabled: true
  engine-mode: 2
```

- **`enabled: true`**: Schakelt het systeem in (staat standaard uit).
- **`engine-mode: 2`**: Activeert de 'nep-ertsen' modus (de beste beveiliging).
