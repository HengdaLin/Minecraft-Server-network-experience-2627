# 🌍 4.5 Chunky (Wereld Pre-generatie)

Om lag tijdens het spelen te voorkomen, gebruiken we de plugin Chunky om de wereld alvast te genereren vóórdat spelers deze ontdekken (pre-generation).

## ⚙️ Wereld genereren (Eenmalig)
Voer deze commando's in via de console wanneer er **geen** spelers online zijn (bijvoorbeeld 's nachts), want dit proces is zwaar voor de server:

1. `chunky radius 5000` (Stelt de grens in op 5000x5000 blokken rondom het midden).
2. `chunky start` (Start het generatieproces).

*Let op: Dit kan enkele uren duren. Je kunt de voortgang in de console zien. Als je de server herstart, kun je later `chunky continue` typen.*
