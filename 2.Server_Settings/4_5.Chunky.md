# 🌍 4.5 Chunky (Wereld Pre-generatie)

Om lag en watchdog-freezes tijdens het spelen of gebruiken van `/tpr` te voorkomen, gebruiken we de plugin **Chunky** om de wereld alvast te genereren vóórdat spelers deze ontdekken (*pre-generation*).

## ⚙️ Wereld Genereren (Eenmalig)

Voer deze commando's in via de Pterodactyl console wanneer er **geen** (of zo min mogelijk) spelers online zijn, want dit proces belast de CPU zwaar:

1. `chunky world world` *(Selecteert de Overworld).*
2. `chunky center 0 0` *(Zet het middelpunt exact op `0, 0`, gelijk aan de instelling van `/tpr`).*
3. `chunky radius 5200` *(Stelt de straal in op 5200 blokken rondom `0, 0` — iets ruimer dan de 5000 blokken `max-range` van `/tpr` zodat ook omliggende chunks klaarstaan).*
4. `chunky start` *(Start het pre-generatieproces).*

*Let op: Dit kan enkele uren duren. Je kunt de voortgang live in de console volgen. Als je de server tussentijds herstart, kun je het proces later hervatten met `chunky continue`.*

## 🛠️ Handige Beheercommando's

| Commando | Doel / Werking |
| :--- | :--- |
| `chunky progress` | Toont het huidige percentage en de geschatte resterende tijd (ETA). |
| `chunky pause` | Pauzeert het genereren tijdelijk wanneer er spelers online komen en de TPS daalt. |
| `chunky continue` | Hervat een gepauzeerde generatietaak. |
| `chunky quiet 10` | Beperkt de console-meldingen tot één update per 10 seconden tegen console-spam. |
| `chunky cancel` | Stopt de huidige taak volledig (reeds gegenereerde chunks blijven bewaard). |

## ⚠️ Koppeling met EssentialsX (`/tpr`)

- De straal van Chunky (`5200` blokken) is direct afgestemd op de `max-range: 5000.0` in `/plugins/Essentials/tpr.yml`.
- Pas je in de toekomst de `max-range` van `/tpr` aan (bijvoorbeeld naar `10000.0`), voer dan eerst opnieuw Chunky uit met een iets grotere radius (`10200`) voordat spelers dit nieuwe gebied kunnen bereiken.
