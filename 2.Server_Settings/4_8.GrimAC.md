# 🛡️ 4.8 GrimAC (Anti-Cheat)

Dit document beschrijft de configuratie en werking van **GrimAC** (V2), de prediction-based anti-cheat plugin op onze PaperMC `26.1.2` server[cite: 1]. GrimAC controleert bewegings-, gevechts- en plaatspakketten van spelers om hacks (zoals Fly, Speed, Reach, NoSlow en Timer) tegen te gaan zonder legitieme spelers te hinderen.

## ⚙️ Basisconfiguratie (`config.yml`)

- **Bestandslocatie:** `/plugins/GrimAC/config.yml`
- **Belangrijkste instellingen:**
  - `alerts.print-to-console: true` *(Stuurt anti-cheat meldingen ook naar de serverconsole).*
  - `client-brand.disconnect-blacklisted-forge-versions: true` *(Blokkeert oude Forge-versies met ingebouwde Reach-exploits).*
  - `Simulation.threshold: 0.001` *(Standaard gevoeligheid voor bewegingsafwijkingen).*
  - `Reach.block-impossible-hits: true` *(Blokkeert aanvallen buiten het mogelijke bereik).*
  - `packet-spam-threshold: 100` *(Kickt spelers die meer dan 100 illegale/geannuleerde pakketten per seconde sturen).*
- **Toepassen:** Gebruik het commando `/grim reload` in-game of in de console om wijzigingen direct door te voeren.

## 🔔 Discord Webhook Alerts (`discord.yml`)

Anti-cheat meldingen (flags) worden automatisch doorgestuurd naar ons Discord-logkanaal zodat staff direct kan meekijken bij verdacht gedrag.

- **Bestandslocatie:** `/plugins/GrimAC/discord.yml`
- **Instellingen:**
  - `enabled: true` *(Schakelt de Discord-koppeling in).*
  - `webhook: "<Discord Webhook URL>"` *(De koppeling naar het staff-alertkanaal).*
  - `include-timestamp: true` *(Voegt een tijdstempel toe aan elke embed).*
- **Weergegeven informatie per alert:** Spelernaam (`%player%`), gedetecteerde check (`%check%`), aantal violations (`%violations%`), Minecraft-versie (`%version%`), gebruikte client/modloader (`%brand%`), ping (`%ping%`) en server-TPS (`%tps%`).
- **Toepassen:** Na het aanpassen van `discord.yml` altijd `/grim reload` uitvoeren.

## 🛠️ Belangrijkste Commando's (Staff)

| Commando | Doel / Werking | Doelgroep |
| :--- | :--- | :--- |
| `/grim alerts` | Zet in-game anti-cheat meldingen voor jezelf aan of uit. | Helper / Mod / Admin |
| `/grim profile <speler>` | Toont gedetailleerde info over een speler (ping, client-versie, client-brand en actieve checks). | Helper / Mod / Admin |
| `/grim spectate <speler>` | Laat je onzichtbaar meekijken met een verdachte speler. | Mod / Admin |
| `/grim stopspectating` | Stopt de GrimAC spectate-modus en zet je terug op je oude locatie. | Mod / Admin |
| `/grim verbose` | Toont gedetailleerde debug
