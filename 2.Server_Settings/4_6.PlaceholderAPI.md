# Technische Documentatie: TAB & SuperVanish Integratie (via PlaceholderAPI)

## 1. PlaceholderAPI (PAPI) Installatie
Standaard TAB-variabelen werken niet altijd goed samen met de netwerk-level vanish van SuperVanish. Hiervoor is de Server-module van PlaceholderAPI vereist.

1. Download de nieuwste versie van **PlaceholderAPI**: [Modrinth Pagina](https://modrinth.com/plugin/placeholderapi)
2. Plaats het `.jar` bestand in de `/plugins/` map via Pterodactyl of SFTP.
3. Herstart de server volledig om de plugin in te laden.

## 2. PAPI Server-Module Activeren
Om de correcte speler-aantallen uit de serverkern te halen, moet de Server-uitbreiding gedownload worden. 

Voer de volgende commando's uit in de server console of in-game (als admin):
```bash
papi ecloud download Server
papi reload
```

Verificatie: De console geeft een groene/succesvolle melding dat de module is gedownload en geladen.
